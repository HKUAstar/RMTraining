Copy and swap idiom create a temporary object and swap the content of the temporary object with the current object.
copy and swap is less efficient than move operation, because it creates a temporary object. The temporary object will be destroyed after the swap
The move operation directly moves the content of the temporary object to the current object by reassigning the pointer.
so it does not need to create a copy of content of the object
